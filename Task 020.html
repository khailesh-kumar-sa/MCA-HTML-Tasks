CSS Selector Demonstration

CSS selectors allow us to target specific HTML elements and apply different styles to them. This page demonstrates four commonly used types of selectors.

1. Element Selector

The element selector targets all elements of a particular HTML type. In this example, the h1 selector changes the color of every h1 element to yellow.

2. Class Selector

The class selector uses a class name and can be applied to multiple HTML elements. This paragraph uses the class-example class and appears in green.

Another paragraph can remain unaffected because it does not have the class-example class.

3. ID Selector

The ID selector targets one specific element using a unique ID. This paragraph has the ID id-example and appears in red.

4. Universal Selector

The universal selector is represented by an asterisk (*). It targets every element on the webpage. Here it is used to apply box-sizing to all elements.

Selector Summary

Element Selector → h1

Class Selector → .class-example

ID Selector → #id-example

Universal Selector → *
