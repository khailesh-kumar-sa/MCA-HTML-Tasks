CSS Box Model

The CSS Box Model describes how the width, padding, border, and margin of an element determine the space it occupies.

My Box

This box has a width of 400px, padding of 20px, a 5px border, and a margin of 30px.

Observe the difference between the specified width of the box and the total space occupied by the box.

The width property specifies the content width. Padding is added around the content, while the border surrounds both the content and padding. Margin creates space outside the border.
