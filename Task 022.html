My Memories

Memories are special moments that we keep with us long after an event has passed. Photographs help us preserve these moments and revisit them whenever we want.

Background Image

This webpage uses a photograph as its background image. The background-image property is used to add the photograph behind the content of the webpage.

Preventing Image Repetition

The background-repeat property controls whether a background image is repeated. By setting it to no-repeat, the image appears only once instead of being tiled across the webpage.

A Special Memory

Every photograph captures a moment in time. Looking back at old photographs can bring back the people, places, experiences, and emotions connected with those moments.

CSS Used

The main properties used for the background are:

background-image: Adds the photograph as the background.

background-repeat: no-repeat; Prevents the photograph from repeating.
