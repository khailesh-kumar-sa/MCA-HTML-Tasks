The section below demonstrates how CSS can control the color, image, position, repetition, and size of a background.

Background Properties

1. background-color

The background-color property sets a background color for an element. Here, red is used as the background color of the image section.

2. background-image

The background-image property places an image behind the content of an element. The provided TVK-related photograph is used here.

3. background-position

The background-position property controls where the background image appears. The value center places the image in the center of the section.

4. background-repeat

The background-repeat property controls whether an image is repeated. The value no-repeat displays the image only once.

5. background-size

The background-size property controls the size of the background image. The value cover makes the image cover the entire section.

About TVK

Tamilaga Vettri Kazhagam, commonly known as TVK, is a political organization in Tamil Nadu. This webpage uses TVK-related content as an example while demonstrating CSS background properties.

The red and yellow gradient provides the main visual background, while the glassmorphism cards allow the background to remain visible behind the content.
